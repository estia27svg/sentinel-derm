Triage that knows when it does not know.

A dermatology screening aid built on conformal prediction. Instead of forcing one label, it returns the set of diagnoses that cannot be ruled out at a 90% coverage guarantee — and refuses to answer when the image is ambiguous, blurry, or not a dermoscopic field.

Held-out evaluation

Every claim, measured.

All numbers below come from images the model never saw during training, calibration, or model selection. Splits are made by lesion, not by image, so near-duplicate photographs cannot leak between sets.

How to read these numbers

Coverage

How often the true diagnosis is inside the returned set. A 90% target means at least 9 in 10 cases on held-out data. It is not the chance that a single answer is correct.

Accuracy and recall

Accuracy is the share of all images where the top label is correct. Recall is the share of a class that the model catches; melanoma recall matters most in screening.

Set size and abstention

One diagnosis is a committed call. Two or more is an abstention because the model cannot separate them. A larger average set means more uncertainty.

Method

Why a prediction set instead of a label.

A classifier that is wrong 15% of the time and never says so is dangerous in screening. Conformal prediction converts any classifier into one that carries a statistical guarantee, at the cost of occasionally returning more than one diagnosis — or none.

  1. 01

    Frozen backbone

    An ImageNet-pretrained EfficientNet-B0 turns each image into a 1,280-dimensional embedding. The backbone stays frozen; a multinomial logistic head is fitted on the training split only.

  2. 02

    Conformal calibration

    On a separate calibration split we compute, per class, the ceil((n+1)(1−α))/n quantile of the nonconformity score 1 − p(y|x). At test time a class enters the prediction set when its probability clears that class’s threshold. Calibrating per class prevents the rare melanoma class from being systematically under-covered.

  3. 03

    Abstention

    A set with one member is a committed answer. A set with two or more members is reported as ambiguity and escalated. An empty set means no known diagnosis explains the image. The interface never hides this.

  4. 04

    Out-of-domain gate

    Inputs are scored by Mahalanobis distance to the nearest class-conditional embedding centre, with the rejection threshold fixed at the 99th percentile of in-distribution calibration scores. Photos that are not dermoscopic skin are rejected instead of being force-fitted to a diagnosis.

  5. 05

    Explanation

    Grad-CAM highlights the region driving the top class. It is a sanity check for the user, not evidence of clinical validity: saliency maps can look convincing while being wrong.

Dataset

Seven diagnostic classes: actinic keratosis, basal cell carcinoma, benign keratosis, dermatofibroma, melanoma, melanocytic nevus, and vascular lesions.

Known limitations

  • Skin-tone coverage. HAM10000 is predominantly lighter-skinned. Performance on darker skin is not established, and models in this space are known to degrade there.
  • Dermoscopy only. The model was trained on specialist dermoscopic images, not smartphone photos. The out-of-domain gate mitigates this but does not solve it.
  • Seven classes. The real differential is far wider. A confidently classified image can still be something the model has no class for.
  • Not a medical device. This is a research prototype submitted to a student hackathon. It must not be used for clinical decisions.
